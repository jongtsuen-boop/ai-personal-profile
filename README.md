4. 确认 README 已更新后关闭 Issue。

## 版本记录与回退

本仓库使用 Git 保存每次提交的版本。只有提交（commit）后的修改才会进入历史。

- 在 GitHub 文件页面选择 **History** 查看历史版本。
- 每次修改使用明确的提交说明。
- 已发布的错误修改使用 `git revert <提交SHA>` 生成撤销提交，保留原始历史；然后推送到远端。
- 避免强制推送或重写共享历史。

## 本地同步

首次下载：

```bash
git clone https://github.com/jongtsuen-boop/ai-personal-profile.git
cd ai-personal-profile
```

每次修改前同步：

```bash
git pull --ff-only
```

编辑后提交并推送：

```bash
git add README.md
git commit -m "docs: 更新个人档案"
git push
```

## 跨 AI 使用方式

把此仓库链接提供给其他 AI，并明确要求读取最新 README。不能访问链接的 AI，可直接粘贴 README 内容。不同 AI 不会自动同步此档案；更新后应重新读取或提供最新版本。示例和待填写项不得被当作真实个人事实。
